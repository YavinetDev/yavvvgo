# Версионирование ЯвьЕдет

- При каждой задаче, меняющей приложение, повысьте версию один раз. Для фикса или мелкой правки увеличьте минорную цифру на 1: `beta v2.3` → `beta v2.4` → `beta v2.5`. Для новой функциональности или редизайна увеличьте мажорную цифру на 1 и сбросьте минорную в `0`: `beta v2.5` → `beta v3.0`.
- Укажите `appVersion=MAJOR.MINOR` в корневом `gradle.properties`; `appVersionCode` увеличьте отдельно на 1 для возможности обновления APK. `app/build.gradle` читает оба значения из корневой конфигурации.
- Синхронно обновите `beta vMAJOR.MINOR` в заголовке и шапке HTML-прототипа `YavEdet-native.html` и перенесите этот HTML в `app/src/main/assets/index.html` перед сборкой APK. Проверьте, что видимая версия, корневой `appVersion` и Android `versionName` совпадают.
